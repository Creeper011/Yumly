# About the Ylwa (wa wa wa) Format
⊹˚. ♡.𖥔 ݁ ˖

Ylwa is Yumly's internal cutesy format, used specifically for structured logging and benchmark results.

## ✿ Why Ylwa?
- Because it maintains the aesthetic of the project.
- It's cute, obviously ˶> ̫ <˶
- I wanted to create another format to avoid the "others format" lol.

## ✿ Formal Specification
For the formal grammar, see the [Ylwa EBNF Specification](ebnf/ylwa.ebnf).

## ✿ Syntax at a Glance

| Element | Syntax | Description |
|---------|--------|-------------|
| Comment | `.> ... <.` | Multiline comment block |
| Block   | `~ Name : ... :` | A named container for data |
| Field   | `- Key ; Value,` | A key-value pair (Value is always a string) |

There's no type system, every value is a string.
Blocks may contain fields, comments, and other blocks. A block opens with
`~ Name :` and closes with `:` on its own line; indentation is only for human
readability.

## ✿ Example

```ylwa
.> Ylwa Benchmark Example <.

.> 
  This language is not a config language;
  it is a representative language for benchmarking yumly.
<.

.> Generated by Yumly Nim Test Runner
  Date: 2026-06-23 20:15:03 <.

~ Summary :
  - Measurements ; 267,
  - Total Time ; 447.4ms,
  - Peak Memory Delta ; 64.293MB,
  - Peak Memory Delta Excluding Stress Tests ; 0.001MB,
  - Peak Memory Delta On Stress Tests ; 64.293MB,
  - Slowest ; pipeline sT0003-large-string case1.yumly,
:

~ Fixture Benchmarks :
  ~ Group stress :
    - Kind ; stress,

    ~ Summary :
      - Tests ; 5,
      - Measurements ; 10,
      - Total Time ; 382.3ms,
      - Slowest ; pipeline sT0003-large-string case1.yumly,
    :

    ~ Fixtures :
      ~ Fixture sT0003-large-string case1.yumly :
        - File ; tests/fixtures/stress/sT0003-large-string/case1.yumly,
        - Total Time ; 221.6ms,
        - Peak Memory Delta ; 0.000MB,

        ~ Operation tokenizer :
          - Time ; 106.7ms,
          - Memory Delta ; 0.000MB,
        :

        ~ Operation pipeline :
          - Time ; 114.9ms,
          - Memory Delta ; 0.000MB,
        :
      :
    :
  :
:
```
